วิธีติดตั้ง K9s Studio (Windows)
================================

1. ดับเบิลคลิก K9s-Studio-Windows-Setup.exe
2. ถ้าขึ้นหน้าจอสีฟ้า "Windows protected your PC" ให้กด More info แล้วกด Run anyway
   (เป็นเรื่องปกติ เพราะโปรแกรมไม่ได้ลงทะเบียนกับ Microsoft ทำแค่ครั้งแรกครั้งเดียว)
3. กด Next > ใส่ key > Install
4. แอปจะเปิดขึ้นมาเอง รอหน้าโหลดจนครบ 100% แล้วเข้าสู่ระบบใช้งานได้เลย

อัปเดต: เมื่อมีเวอร์ชันใหม่ จะมีปุ่ม "อัปเดตเป็น vX" ที่แถบด้านบนของแอป กดครั้งเดียว
ลบโปรแกรม: Settings > Apps > K9s Studio > Uninstall
